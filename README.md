# AI Smart Agriculture — Satellite Land-Use Analysis

DEPI Round 5 · Microsoft Machine Learning track · Group 3 · Instructor: Mahmoud El-Sayed

**Research question:** can we tell farmland apart from other land types using only Sentinel-2
satellite images, and which visual features (color, vegetation, texture) carry that signal?

## Milestones covered here

| Milestone | Content |
|---|---|
| 1 (redo on new data) | Data collection, quality audit, EDA, stratified 70/15/15 split, normalization, augmentation |
| 2 — Advanced Data Analysis & Feature Engineering | 23 hand-crafted features, power transform + scaling, ANOVA / Kruskal–Wallis / Welch t-tests / chi-squared, correlation pruning, mutual information + RFE, PCA, t-SNE, pretrained ResNet-18 embeddings, controlled feature-set comparison |

## Notebooks

| Notebook | What it does |
|---|---|
| `Smart_Agriculture_M2_EuroSAT.ipynb` | EuroSAT audit, EDA, feature engineering, statistical tests, PCA/t-SNE, feature-set comparison |
| `Model_Training_M2.ipynb` | Model training & evaluation: EfficientNet-B0 land-cover classifier (96.6% test accuracy), crop-yield regression (Random Forest), crop recommendation (SVM, 99.1% test accuracy). Runs with local data files; set `PROJECT_DIR` first |
| `Yield_Model_Audit.ipynb` | Re-checks the yield model: the reported R² 0.89 is on imputed + clipped targets; with observed targets and log yield it reaches R² 0.93 (random split) and **0.87 predicting 2011–2014 from 1997–2010** |

## Data

[EuroSAT](https://github.com/phelber/EuroSAT) RGB: 27,000 Sentinel-2 patches, 64×64 px at 10 m/pixel,
10 classes (AnnualCrop, Forest, HerbaceousVegetation, Highway, Industrial, Pasture, PermanentCrop,
Residential, River, SeaLake). Downloaded automatically by `torchvision` on first run (~94 MB).

## Run it

**Google Colab:** upload `Smart_Agriculture_M2_EuroSAT.ipynb`, then Runtime → Run all.

**Locally (macOS / Linux):**

```bash
python3 -m venv .venv
.venv/bin/pip install torch torchvision scikit-learn scikit-image matplotlib seaborn pandas scipy jupyter
.venv/bin/jupyter lab Smart_Agriculture_M2_EuroSAT.ipynb
```

The notebook picks the GPU automatically (CUDA on Colab/NVIDIA, MPS on Apple Silicon, else CPU).
A full run takes about 3 minutes on an M-series Mac.

## Outputs

- `outputs/figures/` — every chart used in the presentation (PNG)
- `outputs/tables/` — splits, extracted features, statistical-test results, feature-set comparison,
  feature-engineering summary, `key_results.json`
- `outputs/resnet18_embeddings.npy` — 512-d embeddings per image (git-ignored, regenerated by the notebook)

The **test split is never used** in this milestone; all comparisons are on the validation split.
